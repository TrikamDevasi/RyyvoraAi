## 3. Image Optimization & Delivery Performance

- **Aspect Ratios**: Standardized to `16:9` across hero banners, card headers, and narrative walkthroughs to guarantee zero Cumulative Layout Shift (CLS).
- **Responsive Wrapper**: Powered by `frontend/components/ui/ResponsiveImage.tsx`, offering:
  - Native browser `loading="lazy"` for all below-the-fold media.
  - Automatic `object-fit: cover` with centered positioning.
  - Three tuned institutional gradients (`navy`, `saffron`, `subtle`) ensuring strict WCAG AAA typography contrast regardless of image brightness.
  - Seamless fallback handling if an image fails to load.
- **Color Temperature Alignment**: Graded in institutional cool navies (`#0B0F17`, `#111827`) with warm saffron accents (`#F59E0B`), matching SkillSense AI's core brand identity.
