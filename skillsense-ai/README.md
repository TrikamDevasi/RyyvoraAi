## 🏛️ Executive Overview & SIH26135 Alignment

In India, vocational skilling tracking historically ceased at course completion or initial self-reported placement figures. State directorates lacked **verifiable longitudinal telemetry**, leading to:
1. **Unverified Placement Figures**: Self-reported numbers inflated without employer validation.
2. **Invisible Career Trajectories**: Zero visibility into 30-day, 90-day, 180-day, and 365-day job retention or wage progression.
3. **Curriculum & Geographical Mismatches**: High trainee output in trades experiencing localized supply saturation.
4. **Data Privacy Deficits**: Lack of purpose-bound, revocable consent mandated under India's **DPDP Act 2023**.

**Ryyvora AI** solves this with a privacy-first **Longitudinal Skilling & Outcome Intelligence Platform** built for the Government of Maharashtra and accredited technical institutions.

## ✨ Key Platform Capabilities

### 1. Maharashtra 36-District Heatmap & Grant Optimization
- **36-District Telemetry Matrix**: Real-time skilling density across Pune, Mumbai, Nagpur, Nashik, Chhatrapati Sambhajinagar, Thane, Solapur, Kolhapur, Amravati, and rural divisions.
- **Neural Fund Allocation Simulator**: Budget slider (₹10 Cr – ₹500 Cr) predicting cohort wage yields and grant disbursements.
- **Regulatory Framework Scanner**: Live audit runner for NSQF, DPDP Act 2023, IEEE 7000 Fairness, and PMKVY 4.0 guidelines.

### 2. NCVET / NSQF Institutional Certification & Capstone Rubrics
- **Multi-Institution Presets**: Seamless switching between *Government Polytechnic Pune, VJTI Mumbai, and GCE Nagpur*.
- **4-Axis NCVET Rubric Modal**: Evaluator scores across *Code Architecture, Security, Performance, and Documentation* (0-25 pts each) before cryptographically signing to the state ledger.
- **Economic Multiplier Simulator**: Calculates cohort fiscal yields (18.3x–27.5x ROI) and generates executive dossiers.

### 3. Employer Validation Queue & Campus Recruitment Suite
- **1-Click HMAC Signing**: Recruiters confirm candidate employment claims, sealing validation confidence to 98%+.
- **Candidate Performance Reviews**: Multi-criteria appraisal center with ratings, narrative notes, and PPO recommendation filters.
- **Campus Placement Drive Suite**: Direct scheduling of on-campus, virtual, and hybrid hackathon hiring drives.

### 4. Sector Skill Council (SSC) & Industry Demand Radar
- **Demand vs Supply Gap Radar**: Compares live corporate job requisitions against state talent availability across modern tech stacks (*Next.js 15, Applied AI, Cloud SRE, Zero-Trust SecOps*).
- **National Occupational Standards (NOS) Matrix**: Accredited Qualification Packs (`SSC/Q0501`, `SSC/Q0702`, etc.) mapped to wage growth curves.
- **Corporate Hiring Wire**: Specialized news feed for apprenticeship alliances, MSDE stipend co-funding, and DPDP advisory briefs.

### 5. Administrator Operations, Fairness & Ledger Audit Logs
- **System Operations Cockpit**: Root control over 148,520 accounts, MFA enforcement, and microservices health.
- **Algorithmic Fairness Telemetry**: IEEE 7000 and 80% 4/5ths Disparate Impact compliance across gender, socio-economic, and regional divisions.
- **Append-Only Cryptographic Audit Ledger**: Immutable system event stream recording all auth, grant, and passport transactions.
- **Compliance Dossier Center**: Instant compilation of official gazette reports, census dossiers, and NCVET audit certificates.

### 6. Trainee Milestone Journey & Verified Digital Passports
- **Longitudinal Milestone Timeline**: Traces trainee progress from Enrollment to 365-day retention checks.
- **Cryptographic SHA-256 Digital Passport**: Tamper-proof, QR-verifiable skill passport with verified GitHub code audit links.

## 🛡️ DPDP Act 2023 Sovereign Privacy Center

Built natively to comply with India's **Digital Personal Data Protection Act 2023**:
- **5-Pillar Sovereign Transparency**: Explains WHAT data is collected, WHY, WHO has access, retention periods, and HOW consent can be revoked.
- **Granular Consent Toggles**:
  - `outcome_tracking`: Longitudinal career tracking.
  - `employer_verification`: Employer validation access.
  - `longitudinal_followup`: Post-certification surveys.
  - `salary_benchmarking`: Anonymized wage analytics.
  - `policy_analytics`: State policy feedback.
- **Instant Revocation**: 1-click consent withdrawal immediately masks candidate PII from talent directories.

## 🚀 Production Deployment Workflow

SkillSense AI is deployed on **Vercel Hobby** infrastructure under the repository owner's account (`TrikamDevasi`).

### Vercel Hobby Policy & Collaboration Restriction
> [!IMPORTANT]
> **Vercel Hobby does not support collaboration for private repositories.**
> If a commit is pushed directly to the `main` branch by any team member other than the project owner, Vercel automatically halts and cancels the deployment with the error:
> *"The deployment was blocked because the commit author did not have contributing access to the project on Vercel. The Hobby Plan does not support collaboration for private repositories."*
> 
> To honor contributor attribution while keeping production deployments seamless on Vercel Hobby, all contributors follow an **Owner-Controlled Deployment Workflow**.

### Workflow Rules & Execution
1. **Feature Branches Only**: Team members must create and work exclusively on dedicated feature branches (`feature/<name>` or `fix/<name>`).
2. **No Direct Pushes to `main`**: Team members must never push production changes directly to the `main` branch.
3. **Pull Requests Required**: All proposed modifications must be submitted via a GitHub Pull Request targeting `main`.
4. **Owner Review & Quality Gate**: The repository owner reviews all incoming PRs, validates test suite passes (`npm test`), and approves changes.
5. **Owner-Controlled Deployment**:
   - **Automated CI/CD**: Merged PRs on `main` trigger `.github/workflows/deploy.yml`, which deploys the production build using the Owner's Vercel token stored in GitHub Secrets.
   - **Manual Fallback**: The repository owner can also deploy locally at any time using:
     ```bash
     git checkout main && git pull origin main
     cd frontend && npx vercel --prod
     ```
6. **Genuine Contributor Attribution**: All commits permanently retain their original author metadata (`git log`), properly crediting every teammate's contributions.

For detailed branching commands, review [docs/CONTRIBUTING.md](file:///c:/Users/trika/Documents/skillsense/TEAM_QUANTUM_CODERS-SU-/skillsense-ai/docs/CONTRIBUTING.md).
